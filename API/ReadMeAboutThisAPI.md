## How you can set it up easily

you only need the python script inside "python_to_CV" to run and give you prices which will be read into "live_price.csv"

One you see the price being updated every 10 seconds as I chose but you can modify, open an excel workbook and import the data file "live_price.csv"

Once you load it, press alt + f11, go to "Insert" at the top, then press modules.

Copy and paste the contents of "10secMacroForExcel.txt" in this folder and then once you have done that press f5 and press "run"

It should have worked, go back to your workbook and check if it updates every 10 seconds( you can change the times but its not useful for some stocks )


Finished.
