# Mathematical Methods in Quantitative Finance: First Principles and Derivations

The goal of this project is to build a rigorous understanding of the mathematical foundations of quantitative finance. The best way to demonstrate true comprehension is to derive complex models from first principles.

### The Learning Philosophy
This project assumes **zero prior knowledge of financial markets**, but requires a **strong foundation in mathematics**.
* **Prerequisites:** At least 1-2 years of university-level calculus and linear algebra exposure. 
* **Progression:** As we advance into more complex algorithms and strategies, the required mathematical maturity will increase respectfully.


### Project Structure
* **Documentation:** I will attempt to estimate the required math skill level for each topic.
* **Format:** "Day $n$" entries represent individual research sessions.
* **Methodology:** Some sessions will focus entirely on conceptual building blocks (e.g., defining Moving Averages) to ensure that the derivation of advanced strategies is fully accessible.
